Comprobando el servidor del proyecto…

Abre la carpeta ProyectoFinalManejo en VS Code. En su terminal ejecuta:

npm run dev

Si PowerShell bloquea npm.ps1, utiliza npm.cmd run dev. No necesitas cambiar la política de seguridad.

Mantén esa terminal abierta y SQL Server en Docker iniciado. Después pulsa Reintentar.
